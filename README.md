# Sparky Study (iPhone)

Tom's study app as a home-screen web app: https://yochrissenor-pixel.github.io/sparky-study/

Open the link in Safari on the iPhone, tap Share, then Add to Home Screen. Reminders are sent by the `Sparky reminders` workflow every 15 minutes.

Built from the Sparky Study source by `phone/build.py`; don't edit files here by hand.
